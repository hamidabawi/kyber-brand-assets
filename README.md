# Kyber Solutions brand assets

Public files that Kyber Solutions email signatures load from the web.

- `kyber-signature-logo.png`: the Kyber Solutions logo used in email signatures (228 x 136, transparent background).
- `signature.html` and `signature.js`: a page that shows one person's signature so it can be copied into a mail app on a phone. It holds no personal details. Each person opens it with their own link; their details sit after the `#` in the address, which a browser never sends to a server. The page only accepts `@kybers.ca` addresses, always links to kybers.ca, runs no outside code and makes no network calls.

## Rules for this repository

- Never rename, move or delete a published file: signatures already in use point at these addresses.
- Never replace a published file with new artwork. Publish it under a new name and re-issue the signatures (mail services remember a picture by its address).
- Nothing personal or confidential belongs here: no names, email addresses, phone numbers, documents or keys. Everything in this repository and its history is public.
