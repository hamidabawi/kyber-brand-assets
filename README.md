# Kyber Solutions brand assets

Public files that Kyber Solutions email signatures load from the web.

- `kyber-signature-logo.png`: the Kyber Solutions logo used in email signatures (228 x 136, transparent background).
- `signature.html`: shows one person's signature so it can be copied into a mail app on a phone. It holds no personal details; each person opens it with their own link.

Do not rename or remove a file here: signatures already in use point at these addresses.
